# RC 群测清单

目标：确认 SPP Audio Studio 在不同 Apple Silicon Mac 上的启动、转换、分离、克隆和模型管理行为。

## 1. 首次启动

当前测试版没有 Apple Developer ID 签名。如果双击被 macOS 阻止：

1. 打开 系统设置
2. 进入 隐私与安全性
3. 找到被阻止的 SPP Audio Studio
4. 点击 仍要打开

这是当前免费分发方式下的预期行为。

## 2. 最小测试

### NCM

- 拖入 1 个自己有权处理的 .ncm
- 选择“源文件旁边”
- 确认生成 MP3 或 FLAC
- 点击试听
- 确认源 .ncm 没被修改或删除

### 人声分离

- 拖入 MP3 / FLAC / WAV
- 默认选择“仅伴奏（去人声）”
- 确认只输出 Instrumental
- 切换“仅人声”和“人声 + 伴奏”再测一次
- 点击试听

### 声音克隆

- 打开默认“盼盼 · 自然口播”
- 保留默认测试文稿
- 点击生成
- 点击试听

### 模型与环境

- 截图“模型与环境”页面
- 尤其关注干净 Mac 是否显示 Runtime 缺失
